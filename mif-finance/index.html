MIF Finance

Windows Closed source

A Windows app for a church treasurer. Record each week's offering, pay back expense claims against their receipts, watch the budget month by month, and hand the year to the next treasurer as one folder.

How a week goes

  1. Open the service

    Create an activity for the service, camp or event: which income stream it belongs to, the date, a name and any remarks.

  2. Add who gave

    Add a row for each giver, or attach a payment screenshot and the app reads the amount and date off it. You check them. Cash with no name is recorded as a lump sum.

  3. Confirm

    Nothing is saved until you confirm. Then the totals on the home screen update.

Details

  • One folder holds the program, the database, the receipts vault and the backups.
  • It backs up the database every time it opens and keeps the last 10.
  • Verify Vault re-checks the fingerprint of every receipt.
  • At year end it writes an Excel report and a one-page PDF summary. A handover zip adds every receipt, a list of which file belongs to which record, and the database.
  • Settings sit behind a password.
  • No account and no subscription. Handing over means giving the next treasurer the folder.
  • MIF Finance is closed source. It was built for one church's treasurer, so there is no public download.
